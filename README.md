# Australian Parking Quiz - React

호주 주차 표지판 퀴즈 게임을 React로 구현한 프로젝트입니다.

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 빌드 미리보기
npm run preview
```

## 기술 스택

- **React 18** - UI 라이브러리
- **Vite** - 빌드 도구
- **Tailwind CSS** - 스타일링
- **Material Icons** - 아이콘

## 프로젝트 구조

```
src/
  ├── components/
  │   ├── Navbar.jsx          # 상단 네비게이션 바
  │   ├── ScenarioCard.jsx    # 시나리오 카드
  │   ├── ParkingSign.jsx     # 주차 표지판 컴포넌트
  │   └── ParkingSpot.jsx     # 주차 공간 버튼
  ├── App.jsx                 # 메인 앱 컴포넌트
  ├── main.jsx                # 진입점
  └── index.css               # 글로벌 스타일
```
